===============================================================================
PIXELL AGENT RUNTIME - APKG DEPLOYMENT FLOW
===============================================================================

This diagram illustrates how the Pixell Agent Runtime deploys agent packages
(.apkg files) from initial request through to a running agent process.

Key Components:
- Supervisor (port 9000): Orchestrates deployments
- Linux User Manager: Creates isolated system users
- Package Downloader: Downloads and caches packages from S3/HTTPS
- Process Manager: Spawns agent processes with user isolation
- Package Loader: Creates venvs and installs dependencies

Key Points:
1. Linux User Isolation: Each agent runs as dedicated system user (agent_xxx)
2. Package Caching: Downloads and extractions cached by SHA256 hash
3. Virtual Environment Reuse: Venvs reused when requirements match
4. Fast Dependency Installation: Prefers 'uv' (10-100x faster than pip)
5. Security: Zip-slip protection, size limits, checksum validation
6. Port Allocation: PAC provides ports (production) or allocated internally
