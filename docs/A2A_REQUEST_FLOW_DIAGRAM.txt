===============================================================================
PIXELL AGENT RUNTIME - A2A REQUEST PROCESSING FLOW
===============================================================================

This diagram illustrates how the Pixell Agent Runtime receives and processes
Agent-to-Agent (A2A) requests through AWS infrastructure and routes them to
individual agent processes.

Key Components:
- AWS ALB: Entry point with TLS termination and path-based routing
- GrpcGateway (port 60000): Routes to agents based on agent ID in path
- PARRoutingInterceptor: Strips ALB routing prefixes before handler
- AgentServiceImpl: Agent's A2A request handler with JSON-RPC 2.0 support

Protocol: gRPC with JSON-RPC 2.0
Capacity: 200 concurrent agents per EC2 instance

Key Points:
1. AWS ALB: Entry point with TLS termination and path-based routing
2. GrpcGateway: Routes to agents based on agent ID in path (50051→60000-60199)
3. PARRoutingInterceptor: Strips ALB routing prefixes before handler
4. Three Handler Patterns: Custom functions, subprocess forwarding, or default
5. JSON-RPC 2.0: Standard A2A protocol with backward compatibility
6. 200-Agent Capacity: Port ranges support 200 concurrent agents per EC2

AWS Resources:
- ALB: pixell-runtime-alb (par.pixell.global)
- Target Groups: pac-agent-{id}-grpc (port 60000)
- EC2: i-09dcb7f387166efd0 (10.0.1.37)
- Port Allocation:
  * A2A (gRPC): 60000-60199 (200 agents)
  * REST: 63000-63199 (200 agents)
  * UI: 65000-65199 (200 agents)
